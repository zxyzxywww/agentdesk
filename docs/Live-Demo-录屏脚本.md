# AgentDesk Live Demo 录屏脚本（约 3 分钟）

> 目的：面试/作品集视频。先提前准备环境，录屏时动作流畅。
> 录屏工具：Windows 自带 Xbox Game Bar（Win+G）或 OBS。

## 0. 准备（录制前完成，不录进视频）

```bash
# 在 agentdesk 目录
uv sync
# 复制 .env.example 为 .env，填入 DEEPSEEK_API_KEY（建议再填 TAVILY_API_KEY）
# 启动服务
uv run uvicorn agentdesk.ui.main:create_app --factory --host 127.0.0.1 --port 8001
```

在 `data/workspace/` 放几个真实感文件（演示更有说服力）：
- `成绩单_2025.csv`、`成绩单_2026.csv`（列名一致，数据不同）
- 一个 `草稿笔记.txt`
- 可选：一张图片、一个 pdf

## 1. 开场（约 20 秒）

- 打开 `http://127.0.0.1:8001`，深色工作台
- 口播：**「这是 AgentDesk，一个通用任务型 Agent 工作台。它能把自然语言任务拆成计划，
  调用工具完成文件与数据处理，还能做网页调研；整个过程每一步都看得见、可干预。」**
- 镜头停留顶部栏：模型（deepseek-chat）、工作目录、累计成本。

## 2. 任务一：合并 CSV（约 50 秒）——展示核心工具链

- 快捷模板选「合并所有 csv」或输入：
  `把工作目录下所有 csv 合并为一个 merged.csv，并汇报总行数和平均分`
- 口播：**「注意右侧：Agent 先给出计划，然后每一步工具调用都会实时滚动——
  读了哪些文件、合并结果如何。」**
- 任务完成 → 切到「验收」Tab：展示摘要、产出文件、步数、成本（¥0.00x，强调成本低）。
- 点击「导出报告」，下载 .md，展示内容（可选）。

## 3. 任务二：危险操作确认 + 撤销（约 40 秒）——展示安全设计

- 输入：`把 草稿笔记.txt 的内容改成「已修改」`（覆盖已有文件）
- 口播：**「注意：覆盖已有文件属于危险操作，Agent 不会自作主张——弹窗请求确认，
  并展示参数。我点『拒绝，换方案』，Agent 就会调整。」**
- 点拒绝 → Agent 换方案（如先列出文件再问）。
- 再演示确认+撤销：输入一个**删除**任务（`删除草稿笔记.txt`），点「确认执行」，
  文件消失；切到「撤销」Tab → 点「恢复」→ 文件回来。
- 口播：**「删除前自动备份，一键还原——这就是为什么敢让它动手。」**

## 4. 任务三：网页调研（约 50 秒）——展示搜索能力

- 输入：`调研一下 LLM agent 框架（LangGraph / AutoGen / CrewAI）的现状与差异，
  写一份带引用来源的调研笔记`
- 口播：**「现在让它做资料调研：搜索、抓取多个网页，把带来源的资料汇总，
  最后写出带引用的笔记——每个结论都能溯源到 URL。」**
- 展示执行面板里 research_report 的抓取过程与验收摘要。

## 5. 收尾（约 20 秒）

- 切回顶部成本：**「三组任务全部完成，总成本不到 ¥0.1——纯 API、低成本、
  每一步可监督可撤销。」**
- 口播：**「代码 93 个离线测试全绿、ruff/mypy 零告警、Docker 可部署，
  完整代码和文档在 GitHub。谢谢观看。」**

## 提示

- 如果任务意外走到护栏（步数/成本上限），如实展示并口播「这是护栏在起作用」——反而是加分点。
- 录屏前先完整演练一遍真实任务，确认 API key 可用、搜索能通。
- 视频分辨率 1080p，配 2 倍速字幕更专业。
